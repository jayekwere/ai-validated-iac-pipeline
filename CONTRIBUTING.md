# Contributing

Run the documented local acceptance suite before opening a PR. Keep the compiler vocabulary, independent plan checks and adversarial fixtures aligned. Add a negative fixture for each new infrastructure capability. Never broaden a policy only to make a sample pass. Document scanner exceptions with exact resource scope, primary service documentation and an `expires` date no more than 365 days ahead; an expired exception fails the Trivy security decision until it is re-reviewed or removed. Pin dependency and Action updates and review their release changes. Do not add apply, automatic merge or privileged PR execution.
